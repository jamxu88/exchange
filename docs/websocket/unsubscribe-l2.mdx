---
title: "Unsubscribe L2"
description: "Stop receiving an aggregated L2 market-data stream on the current socket."
---

Use `unsubscribe` when you want to stop receiving aggregated market data for the current subscription.

<RequestExample>

```json Client Message
{"op":"unsubscribe","channel":"l2","market":"BTC-USD"}
```

</RequestExample>

## Client fields

- `op` must be `unsubscribe`.
- `channel` must be `l2`.
- `market` is the subscribed market you want to stop receiving.

## Notes

- Unsubscribe affects only the specified market-data subscription.
- Authentication state on the socket is unchanged.
