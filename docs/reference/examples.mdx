## Provision a competition user

```bash
curl \
  -X POST \
  -H "Authorization: Bearer ADMIN_API_TOKEN" \
  -H "content-type: application/json" \
  https://exchange.jamesxu.dev/api/v1/admin/users \
  -d '{"username":"team-alpha"}'
```

## Fetch authenticated account data

```bash
curl -H "x-api-key: YOUR_API_KEY" \
  https://exchange.jamesxu.dev/api/v1/user

curl -H "x-api-key: YOUR_API_KEY" \
  https://exchange.jamesxu.dev/api/v1/positions

curl -H "x-api-key: YOUR_API_KEY" \
  'https://exchange.jamesxu.dev/api/v1/open-orders?market=BTC-USD'
```

## Submit an order from JavaScript

```ts
const response = await fetch("https://exchange.jamesxu.dev/api/v1/orders", {
  method: "POST",
  headers: {
    "content-type": "application/json",
    "x-api-key": process.env.EXCHANGE_API_KEY!,
  },
  body: JSON.stringify({
    market: "BTC-USD",
    side: "BUY",
    price: 100,
    quantity: 2,
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

const payload = await response.json();
console.log(payload);
```

Sell orders can be submitted from flat inventory. The backend enforces only the per-market worst-case net position limit, so a trader can go short as long as all currently open orders plus current net position remain within `+/-1000`.

## WebSocket session example

```js
const socket = new WebSocket("wss://exchange.jamesxu.dev/ws");

socket.addEventListener("open", () => {
  socket.send(JSON.stringify({
    op: "authenticate",
    api_key: process.env.EXCHANGE_API_KEY,
  }));

  socket.send(JSON.stringify({
    op: "subscribe",
    channel: "l3",
    market: "BTC-USD",
  }));
});

socket.addEventListener("message", (event) => {
  const message = JSON.parse(event.data);
  console.log(message);
});
```
