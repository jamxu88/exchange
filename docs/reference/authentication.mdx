## Assigned API keys

Ops hands each competitor or trading team a single API key before the event. That key is the credential you use for every REST request and WebSocket session, so keep it safe.

Start your session with [GET /api/v1/user](/rest/user) to confirm your identity, then call [GET /api/v1/portfolio](/rest/portfolio) to understand your positions and hard limits before you trade.

## REST trader auth

Authenticated trader routes require:

```http
x-api-key: YOUR_API_KEY
```

Used for:

- `GET /api/v1/leaderboard`
- `GET /api/v1/user`
- `GET /api/v1/markets` does not require auth
- `GET /api/v1/positions`
- `GET /api/v1/portfolio`
- `GET /api/v1/fills`
- `GET /api/v1/open-orders`
- `POST /api/v1/orders`
- `PATCH /api/v1/orders/{order_id}`
- `DELETE /api/v1/orders/{order_id}`

## Rate limit

Authenticated competitor operations are limited to `100 ops/sec` per API key.

If you exceed that per-user limit, the server responds with:

```json
{
  "error": "per-user rate limit exceeded: max 100 ops/sec"
}
```

This limit applies to:

- authenticated REST account and trading routes such as `/api/v1/user`, `/api/v1/portfolio`, and `/api/v1/orders`
- authenticated WebSocket trading messages: `submit_order`, `cancel_order`, and `amend_order`

## WebSocket auth

The WebSocket endpoint is:

```text
wss://exchange.jamesxu.dev/ws
```

Authenticate by sending:

```json
{"op":"authenticate","api_key":"YOUR_API_KEY"}
```

Successful response:

```json
{
  "type": "authenticated",
  "trader_id": "9d64e278-8b56-46e9-9cab-18c5b22f2fb9",
  "username": "team-alpha"
}
```

## Notes

- No passwords, JWTs, or OAuth flows are involved—just the API key you were given.
- Expect `role = "trader"` in your `/api/v1/user` response; if it looks wrong, pause and ping ops.
- You can watch public market data before authenticating, but only a successful `authenticate` gives you order entry and user events.
- That `100 ops/sec` limit only hits authenticated competitor actions, so public endpoints like `/api/v1/markets` stay unlimited.
- This guide skips admin-only APIs; focus on the competitor surface area listed above.
