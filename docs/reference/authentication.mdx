## Assigned API keys

Competitors do not self-register. Each team or trader receives an API key from the competition operator.

That API key is your only credential for the public trading API.

## REST trader auth

Authenticated trader routes require:

```http
x-api-key: YOUR_API_KEY
```

Used for:

- `GET /api/v1/leaderboard`
- `GET /api/v1/user`
- `GET /api/v1/markets` does not require auth
- `GET /api/v1/positions`
- `GET /api/v1/portfolio`
- `GET /api/v1/fills`
- `GET /api/v1/open-orders`
- `POST /api/v1/orders`
- `PATCH /api/v1/orders/{order_id}`
- `DELETE /api/v1/orders/{order_id}`

## WebSocket auth

The WebSocket endpoint is:

```text
wss://exchange.jamesxu.dev/ws
```

Authenticate by sending:

```json
{"op":"authenticate","api_key":"YOUR_API_KEY"}
```

Successful response:

```json
{
  "type": "authenticated",
  "trader_id": "9d64e278-8b56-46e9-9cab-18c5b22f2fb9",
  "username": "team-alpha"
}
```

## Notes

- There are no user passwords.
- There is no JWT or OAuth flow.
- WebSocket market data can be subscribed to before authentication, but trading and user-scoped events require a successful `authenticate` message.
- Internal admin and operator routes exist, but they are intentionally omitted from this public competitor guide.
