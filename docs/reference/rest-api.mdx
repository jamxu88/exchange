## Data model notes

- `side` is `BUY` or `SELL`
- `price`, `quantity`, and `remaining` are integer `u64` values
- traders can buy from flat, sell from flat, go long, and go short
- risk is enforced with a fixed per-market worst-case net limit of `+/-1000`
- `open-orders` and `fills` accept an optional `market` query parameter
- leaderboard ranking is based on current marked PnL

## What is intentionally omitted here

Internal operator and admin endpoints are not part of the public competitor docs. The Mintlify site is meant to answer one question cleanly: how a competitor connects, reads state, and trades.
