---
title: "Get Leaderboard"
api: "GET /api/v1/leaderboard"
description: "Read the current competition leaderboard ranked by marked PnL."
---

Call this endpoint when you want the current public leaderboard snapshot.

<RequestExample>

```bash Request
curl https://exchange.jamesxu.dev/api/v1/leaderboard \
  -H "x-api-key: YOUR_API_KEY"
```

</RequestExample>

<ResponseExample>

```json 200 Response
[
  {
    "rank": 1,
    "trader_id": "3e071303-fc81-4e1e-a739-04e4902717cf",
    "username": "team-alpha",
    "net_pnl": 125,
    "realized_pnl": 80,
    "unrealized_pnl": 45,
    "gross_exposure": 300
  }
]
```

</ResponseExample>

## Headers

<ParamField header="x-api-key" type="string" required>
  Assigned competitor API key.
</ParamField>

## Response fields

<ResponseField name="[]" type="object[]" required>
  Current live leaderboard ranking.
</ResponseField>

<ResponseField name="[].rank" type="u64" required>
  Current leaderboard rank, starting at `1`.
</ResponseField>

<ResponseField name="[].trader_id" type="string" required>
  Stable trader identifier.
</ResponseField>

<ResponseField name="[].username" type="string" required>
  Human-readable competitor label.
</ResponseField>

<ResponseField name="[].net_pnl" type="i64" required>
  Sum of realized and unrealized PnL used for ranking.
</ResponseField>

<ResponseField name="[].realized_pnl" type="i64" required>
  PnL already locked in from closed or settled quantity.
</ResponseField>

<ResponseField name="[].unrealized_pnl" type="i64" required>
  Mark-to-market PnL on current open positions.
</ResponseField>

<ResponseField name="[].gross_exposure" type="u64" required>
  Absolute current exposure across open positions.
</ResponseField>

## Notes

- Ranking is based on `net_pnl`.
- `gross_exposure` reflects current absolute position size, not just realized activity.
- After settlement, the leaderboard may change immediately as unrealized PnL becomes realized.
- This endpoint reflects **live** standings during the event; official final rankings may be published separately after markets are settled and locked.
