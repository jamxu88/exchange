---
title: "GET /api/v1/user"
description: "Fetch the authenticated trader profile associated with your API key."
---

Use this endpoint after login to confirm which trader identity the backend sees.

## Auth

Send your assigned API key:

```http
x-api-key: YOUR_API_KEY
```

## Request

```bash
curl https://exchange.jamesxu.dev/api/v1/user \
  -H "x-api-key: YOUR_API_KEY"
```

## Example response

```json
{
  "trader_id": "c7f8c572-8a50-4dbd-a1e1-9f452774b636",
  "username": "trader",
  "api_key": "trader",
  "created_at": "2026-03-18T19:14:31.447224Z"
}
```

## Notes

- `trader_id` is the stable identity used throughout fills and portfolio responses
- `username` is the human-readable label used in leaderboard and operator messaging
