---
title: "PATCH /api/v1/orders/{order_id}"
description: "Reduce the remaining quantity on an existing open order."
---

Amend only changes the `remaining` quantity, and it cannot increase the order.

## Auth

```http
x-api-key: YOUR_API_KEY
```

## Path parameter

- `order_id` the order you want to change

## Request body

```json
{
  "remaining": 1
}
```

## Request

```bash
curl \
  -X PATCH \
  -H "x-api-key: YOUR_API_KEY" \
  -H "content-type: application/json" \
  https://exchange.jamesxu.dev/api/v1/orders/ORDER_ID \
  -d '{"remaining":1}'
```

## Example response

```json
{
  "order": {
    "id": "66377526-7b98-485a-8c40-7024e68fa3c5",
    "trader_id": "9d64e278-8b56-46e9-9cab-18c5b22f2fb9",
    "market": "BTC-USD",
    "side": "BUY",
    "price": 100,
    "quantity": 2,
    "remaining": 1,
    "created_at": "2026-03-18T15:28:01.342510Z"
  }
}
```

## Notes

- you cannot increase `remaining`
- amending to zero is not supported; use cancel instead
- you can only amend your own order
