This site documents the public Exchange API surface for market data, trading, account state, and operator workflows.

## Base URLs

- REST: `https://exchange.jamesxu.dev`
- WebSocket: `wss://exchange.jamesxu.dev/ws`
- OpenAPI JSON: `https://exchange.jamesxu.dev/api-doc/openapi.json`
- Swagger UI: `https://exchange.jamesxu.dev/docs`

## In this documentation

- Authentication and request headers
- REST endpoints for markets, account reads, orders, admin control, and leaderboard
- WebSocket messages for authentication, market data, trading, and user events
- Resync behavior for sequence gaps and reconnects
- Error codes and concrete client examples

## Authentication model

- Trader routes use assigned API keys in `x-api-key`
- Admin routes use a bearer token in `Authorization`
- WebSocket sessions authenticate with `{"op":"authenticate","api_key":"..."}` on the socket
