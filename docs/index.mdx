This site documents the competitor-facing Exchange API surface for market data, trading, positions, fills, and leaderboard access.

The public Mintlify docs intentionally focus on what a trader needs during the competition. Internal operator and admin workflows are not part of this site.

## Base URLs

- REST: `https://exchange.jamesxu.dev`
- WebSocket: `wss://exchange.jamesxu.dev/ws`

## What you can do as a competitor

- fetch the current market list and lifecycle state
- authenticate with your assigned API key
- read your profile, positions, portfolio, fills, and open orders
- submit, amend, and cancel orders over REST or WebSocket
- subscribe to live L3 market data and user-specific trade events
- react correctly to market disablement, settlement, and resync requests

## Authentication model

- Your operator assigns you a single API key.
- Authenticated REST requests send that key in `x-api-key`.
- WebSocket sessions authenticate with `{"op":"authenticate","api_key":"..."}`.
- There is no user registration or password flow.
