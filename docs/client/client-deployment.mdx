## Current state

- The exchange backend is live on EC2.
- The client is not yet deployed as the canonical production UI.
- Client deployment target remains ECS.

## Environment variables

Use these for a deployed client:

```text
NEXT_PUBLIC_EXCHANGE_HTTP_URL=https://exchange.jamesxu.dev
NEXT_PUBLIC_EXCHANGE_WS_URL=wss://exchange.jamesxu.dev/ws
NEXT_PUBLIC_EXCHANGE_MARKETS=BTC-USD,ETH-USD,SOL-USD
```

`NEXT_PUBLIC_EXCHANGE_API_KEY` is optional and mainly useful for local testing or a pinned kiosk-like client. Admin access is now determined by backend validation, not a client-side key list.

## ECS notes

Still needed around deployment:

## Important current caveat

The exchange origin is loopback-only on the EC2 host. Browser clients should use `https://exchange.jamesxu.dev` and `wss://exchange.jamesxu.dev/ws` directly. Public port `80` is not currently redirecting, so use the HTTPS URL explicitly.
